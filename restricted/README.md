# Restricted research-team data

This directory is not part of the public dataset.

- `participant_key.csv` contains direct identifiers (participant names) linked to study pseudonyms.
- `vr_experiment_internal_pseudonymized.csv` contains exact demographics and IPD-derived measurements.

Access is limited to approved study personnel and must comply with the consent form, ethics/IRB approval, institutional policy, and applicable data-protection requirements.

Never make this repository public. Removing these files in a later commit will not remove them from Git history. For Open Science publication, create a new repository or clean export containing only the reviewed anonymous dataset, analysis code, and public documentation.
